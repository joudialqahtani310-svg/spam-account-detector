# 🤖 Multilingual Bot & Spam Account Detector

An AI-powered web application that detects automated bot accounts and spam content in Arabic and English using XGBoost and NLP text analysis.

---

## 🛠️ Key Features
- **Multilingual Analysis:** Evaluates Arabic and English text patterns and spam keywords.
- **Hybrid Feature Engine:** Combines text features (TF-IDF) with profile numerical metadata (Follower-to-Following ratio, tweet velocity).
- **Behavioral Indicators:** Highlights explicit risk factors (e.g., abnormally high post volume, repetitive punctuation).
